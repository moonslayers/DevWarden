# Layouts Settings

## Wayfinder route modules are nested by route-name segments
Dot-separated route names (bot.memories.*) become nested folders (routes/bot/memories); flat route names (memories.index, bot, providers) are flat modules (routes/memories). Memories moved from settings to top-level routes memories.index/memories.destroy, so the import is now `@/routes/memories`. Verify the actual file under resources/js/routes/ before importing. Route/action files are gitignored build artifacts regenerated by vite build — never edit them by hand.
